🔐 OAuth 2.0 Sample SPA

Demonstration of Authorization Code Flow with PKCE

Welcome!

This is a sample Single Page Application demonstrating the OAuth 2.0 Authorization Code flow with PKCE (Proof Key for Code Exchange).

What happens when you click Login?

  1. Application generates a secure PKCE code verifier and challenge
  2. You're redirected to the Identity Server's login page
  3. After successful login, you're redirected back with an authorization code
  4. Application exchanges the code for access and ID tokens
  5. Your user information is displayed
